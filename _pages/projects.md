Selected code releases from my research. The full list is on [GitHub](https://github.com/FaezeGhorbanpour).

### [Latent-Space Intervention for Cross-Lingual Factual Consistency](https://github.com/FaezeGhorbanpour/LatentInterventionCrosslingualFactuality)

Activation-level interventions in a multilingual model's latent space that make its factual answers more consistent across languages, with no drop in accuracy. Code for the EMNLP 2026 (Findings) paper.

### [LLM Sensitivity to Long Inputs](https://github.com/FaezeGhorbanpour/LLMsHarmSensitivityInLongInputs)

Experiments measuring how the safety behavior of instruction-tuned LLMs changes as inputs grow longer. Code for the EMNLP 2026 (Main) paper.

### [Label-Specific Soft Prompt Tuning](https://github.com/FaezeGhorbanpour/LabelSoftPromptTuning)

Parameter-efficient transfer learning with per-label soft prompts and adapters that match full fine-tuning while training under 1% of a model's parameters. Code for the NAACL 2025 paper.

### [Cross-Lingual Nearest-Neighbor Retrieval for Data-Efficient Classification](https://github.com/FaezeGhorbanpour/MultilingualDataEfficientDetection)

A retrieval-based cross-lingual pipeline that reaches supervised-level performance with roughly 50 labeled examples per language. Code for the EMNLP 2025 paper.
